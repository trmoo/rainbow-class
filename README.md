# 🌈 일곱 빛깔 무지개 학급 · The Seven-Color Rainbow Class

한국 고등학교 담임의 「무지개 학급 경영」 사례를 해외 학회에서 발표하기 위한 **웹 슬라이드**입니다.
한 화면 안에서 **한국어 ⇄ English** 를 바로 바꿀 수 있습니다. 모두 19장, 장마다 한·영 발표자 노트가 붙어 있습니다.

**바로 보기 → https://trmoo.github.io/rainbow-class/** (`#ko/1` 을 붙이면 한국어로 열립니다)

## 발표할 때

발표장에서는 인터넷이 끊길 수 있으니 빌드한 `dist/index.html` 을 노트북에 받아 두는 편이 안전합니다.
`dist/index.html` 을 더블클릭해 크롬·엣지로 엽니다. **인터넷이 없어도 열립니다**(글꼴·그림이 파일 안에 들어 있습니다).

| 키 | 하는 일 |
|---|---|
| → · Space · PageDown | 다음 장 (발표용 리모컨 그대로 됩니다) |
| ← · PageUp | 이전 장 |
| **L** | 한국어 ⇄ English (오른쪽 위 스위치로도) |
| **P** | 발표자 창 — 현재·다음 장, 노트, 경과 시간. 노트북 화면에서 보고 프로젝터에는 슬라이드만 |
| N | 노트를 화면 아래에 띄우기 (연습할 때) |
| M | 목차 (19장 썸네일) |
| F | 전체 화면 |
| B 또는 . | 화면 가리기 |
| ? | 단축키 보기 |

* 마우스를 움직이면 위쪽에 단추 띠가 나타났다가 2.5초 뒤 숨습니다.
* 주소 끝의 `#en/7` 은 「영어, 7번째 장」입니다. 그대로 북마크하면 그 장에서 열립니다.
* 발표자 창이 열리지 않으면 주소창 오른쪽의 **팝업 허용**을 눌러 주세요.
* **PDF 로 내기** — 단추 띠의 [PDF 저장] (또는 Ctrl+P) → 대상 「PDF로 저장」.
  지금 보고 있는 언어로 19장이 한 쪽씩 나옵니다(16:9). 학회에 미리 내야 할 때 씁니다.

## 문구 고치기

발표 문구는 모두 **`src/slides.js` 한 곳**에 있습니다. `t('한국어', 'English')` 가 한 쌍입니다.

* 학회 이름·날짜는 맨 위 `META.conference` · `META.date` 에 적습니다. 학회 이름은 「 · 」 마다 표지에서 한 줄씩 나뉩니다(비우면 빨간 점선 칸이 뜹니다).
* 17장의 빨간 점선 칸은 `todo` 를 지우고 `voices: [t('…', '…')]` 로 바꾸면 학생 목소리 상자가 됩니다.
* 글자 꾸밈 — `**굵게**`, `==형광펜==`, `{{易地思之}}`(한자는 대만 글꼴로 보입니다).

## 만들기

```bash
npm install      # 처음 한 번
npm start        # 고치면서 보기 (http://localhost:5173)
npm run build    # 내용 점검 → dist/index.html 한 파일 → 빌드 점검
```

`npm run check` 는 「한·영 둘 다 채웠는가, 노트가 있는가, 전화번호·다른 분 성함이 섞이지 않았는가」를 봅니다.
